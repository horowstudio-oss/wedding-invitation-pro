# Wedding Invitation Template

A static, mobile-first wedding invitation inspired by the supplied reference video.

## Quick start
1. Upload all files to a GitHub repository.
2. Put your own images in `assets/hero.jpg` and `assets/venue.jpg`.
3. Put your music file in `assets/music.mp3`.
4. Edit **only `config.js`** for names, date, venue, timeline, colors and text.
5. Enable GitHub Pages: Repository → Settings → Pages → Deploy from branch → `main` / root.

## RSVP
By default RSVP is a front-end demo and saves to the visitor's browser only.
To collect real submissions, set `rsvpEndpoint` in `config.js` to your own API/Form endpoint.

## Important
Browsers restrict autoplay audio. This template starts music when the guest taps the wax seal, which counts as user interaction.

## Assets
The reference video itself is NOT redistributed. Replace the placeholder files with licensed/owned wedding photography and audio.
